UNInf.setMode(mode) -- Sets your mode to the input mode assuming it is available

UNInf.getPressure() -- Returns the mode's current pressure

UNInf.setPressure(val) -- Allows you to set the current pressure, assuming the mode allows it

UNInf.inflate(val) -- Increases your pressure by the input value, assuming the mode allows it

UNInf.deflate(val) -- Decreases your pressure by the input value, assuming the mode allows it

UNInf.checkWhitelist(wlist) -- Checks the provided white list to see if your conditionals match what is inside. Requires a table. Anything with a - infront of it will be considered blacklisted and fail the check if the conditional is true

UNInf.checkPressureRange(minInf, maxInf) -- Checks to see if your pressure is between the two given percentages, returning true or false

UNInf.annoyLog(msg, class, id) -- Sends msg as a warning to the user's chat. ID is used to ensure it is only sent once if the user keeps activating the send condition. (Can be disabled by setting UNInf.reportLogs to false)

UNInf.clock -- Value ticks up once per tick, and can be utilized for anything related to timing. Good with % (modulus)

UNInf.insertToGroups(module) -- Handles table insertion automatically. What table(s) the module is inserted into is based off of the name of the event you have added

UNInf.ticks -- Table for all tick only modules events

UNInf.renders -- Table for all render only modules events

UNInf.post_world_renders -- Table for all post world render modules events

popping:safePop(void) -- Calls the pop behaviour ONLY if you meet the input conditions. Otherwise it does nothing. Void determines if you should be fully deflated when possible

popping.playSound -- The variable used to determine if the sounds are played when you pop. Set to true to have the module play a boom, set to false to prevent this. Useful if the mod you're using has a boom sound of its own
